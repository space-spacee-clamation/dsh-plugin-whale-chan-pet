# 角色素材生成提示词（whale-chan pet）

本文件是给图像生成 AI 的提示词包，依据插件**实际的素材使用方式**编写。每张图都按"生成 → 我可以直接内联进 `lib/client.js`"的标准写。

## 一、素材是怎么被使用的（硬约束的来源）

| 状态 | 画布比例 | 原始像素 | 触发时机 | 对美术的硬约束 |
|---|---|---|---|---|
| `resting` | 16:9 横 | 124×69 | 空闲、待机 | 横向舒展构图；主体贴底 |
| `working` | 13:10 横 | 116×89 | 有会话正在跑 | **必须横构图 + 面前有笔电，屏幕空白且在画面右下**（插件把"正在工作的会话数"数字画在屏幕上） |
| `sleeping` | 4:3 横 | 115×88 | 空闲超过设定时间 | 横向躺卧；可画 `Z z z`（原素材就有） |
| `waiting` | 4:5 竖 | 89×114 | 等你确认/输入 | 竖构图；可画一个 `?` 图形 |
| `celebrate` | 5:6 竖 | 92×110 | 任务正常完成 | 竖构图；**不要画星星/彩带**（界面会自己叠加 ✦ ✧） |
| `error` | 近 1:1 | 100×106 | 任务出错 | 方构图；可画裂开的卡片 |
| `icon.svg` | 1:1 | 256×256 | 插件管理器图标 | 头像/半身最清楚 |

渲染规则（已从 `src/pet.css`、`src/widget.js`、`src/bubble-layout.js` 核实）：

1. 图片显示在一个**固定 156×156 px** 的方框里，`object-fit: contain` + `object-position: center bottom` → **比例决定显示大小，底边对齐**。
   - 16:9 → 显示 156×88；4:3 → 156×117；1:1 → 156×156；4:5 → 125×156。
   - 所以宽画布的角色显得小，这是原素材的既定取舍，保持一致即可。
2. **气泡锚定在"图片可视区顶部"**（`visibleHeight = min(可用高度, 图宽/宽高比)`，再向上 28px）→ 画布顶部留大片空白，会让文字气泡飘得离头顶很远。**主体尽量占满，顶部别留白。**
3. 插件自己会加：整体柔和投影、地面椭圆（`.ground`）、celebrate 的闪光（`.sparkles`，位置固定在左上/右上/右中）、带文字的思考气泡 → **图里不要重复画这些**。
4. 每个状态都有 CSS 动画（呼吸/打字晃动/歪头/跳跃/起伏/抖动，`transform-origin: 50% 90%`）→ 姿势要"整体可动"，不要依赖画布外的元素。
5. 原素材是**带白色粗描边的贴纸风**（见 `docs/images/whale-states.png`）→ 深色主题下轮廓才清楚，建议保持一致。

## 三、主提示词（每张都放在最前面）

```text
参考图中的第一张是我的角色设定（Q版鲸鱼娘三视图），第二张是姿势与构图参考。请只从第一张提取角色本身（正面视角），忽略三视图排版、中文标签和背景；只从第二张借用姿势、构图和画布比例，不要复制其中的鲸鱼形象。

【角色锁定】必须逐项保持一致：
- 比例：Q版 chibi，约 2.5 头身，大头小身、短手短腿。
- 头发：深藏青到亮蓝的长卷发，发梢渐变为浅蓝；齐刘海；两侧各一只深蓝色鲸鱼鳍状耳鳍（边缘浅灰白）。
- 头饰：白色荷叶边女仆发带；头顶一撮向上翘的深蓝色鲸鱼尾状呆毛；发带右侧一个亮蓝色蝴蝶结。
- 服装：深藏青女仆连衣裙，白色荷叶边领口与袖口；白色围裙，中央有小鲸鱼刺绣；胸前深色蝴蝶结配金色小扣；裙摆白色蕾丝边 + 金色星星与小蝴蝶结纹样；白色花边长袜 + 深蓝玛丽珍鞋。
- 身后：一条深蓝色鲸鱼尾巴，带浅灰斑纹和浅色腹部。
- 脸：大颗蓝色眼睛（高光明显）、腮红、小嘴。
- 画风：干净统一的赛璐璐平涂；深蓝近黑描边、线宽一致；颜色明快、对比清晰。
- 外轮廓：沿整只角色加一圈较粗的纯白描边（贴纸切边风），保证在深色和浅色界面上都清晰。

【通用技术要求】
- 纯透明背景（PNG，带 alpha 通道）：不要任何背景色、渐变、地面、光晕。
- 画面中只有一个角色、一个固定姿势；不要分格、不要三视图、不要重复人物。
- 角色居中并尽量占满画布：主体高度约占画布 85%~95%，底边贴近画布下沿（留白不超过 2%），左右各留 3%~5%。
- 不要画：地面或椭圆投影（界面会自己加）、对话气泡/思考气泡（界面会自己加）、文字、数字、水印、签名、logo、外框。
- 平视视角，正面或微侧面；不要裁切到角色任何部位。

【负面词】low quality, blurry, extra fingers, extra limbs, background scenery, gradient background, drop shadow, ground shadow, speech bubble, frame, watermark, signature, text, multiple views, grid layout, cropped limbs
```

## 四、六个状态（接在主提示词后面，逐张生成）

**参考图**：角色设定 `D:\大白鲸小剧场\dreammaker-asset.png` ｜ 姿势参考 `...\docs\images\whale-states.png` 的对应格 ｜ 原始矢量 `...\assets\<state>.svg`

### 1. resting（待机）— 16:9 横，建议 1600×900 ｜ 原素材 124×69 ｜ 总览格：第二行中
```text
姿势：侧坐在地上，双腿向左侧伸出并拢，双手轻放在膝上或围裙上；鲸鱼尾巴自然向右后方铺开，占画面右侧空间。
表情：放松地微笑，眼睛柔和睁开。
构图：横向舒展，人物贴近画布下沿。
```

### 2. working（工作中）— 13:10 横，建议 1040×800 ｜ 原素材 116×89 ｜ 总览格：第一行左
```text
姿势：坐在小书桌前，面对一台打开的笔记本电脑，身体微微前倾，双手放在键盘上做打字动作；尾巴自然垂在身侧。
硬性要求：笔记本电脑屏幕朝向观众、完全空白（不要任何画面、文字、数字），屏幕位于画面偏右下位置（约在画面宽度的 60%~100%、高度的 45%~85% 区域），带轻微透视倾斜。
表情：专注、眉毛微皱、抿着嘴。头顶可有一小团努力的小汗滴或两颗小星星。
```

### 3. waiting（等你确认）— 4:5 竖，建议 820×1050 ｜ 原素材 89×114 ｜ 总览格：第一行中
```text
姿势：站直，双手在胸前扶着一块完全空白的小白板/平板（板面不写任何字），身体微微前倾；尾巴竖在身后。
表情：睁大眼睛、头微微歪着，疑惑又期待地看向前方。
可选：头部右上方画一个空心的「?」图形；不要画思考气泡，不要写任何字。
```

### 4. celebrate（完成庆祝）— 5:6 竖，建议 860×1030 ｜ 原素材 92×110 ｜ 总览格：第一行右
```text
姿势：双脚离地跳起，双手高举欢呼，尾巴开心地向上翘。
表情：张嘴大笑，眼睛弯成月牙。
注意：不要画星星、彩带、纸屑（界面会自己在四周叠加闪光），头顶与两侧留出一点空白。
```

### 5. sleeping（打盹）— 4:3 横，建议 1040×800 ｜ 原素材 115×88 ｜ 总览格：第二行右
```text
姿势：侧躺或趴着睡着，头枕在自己的尾巴或手臂上，尾巴卷在身边；闭眼、嘴巴微张、脸颊有睡意红晕。
可以画 2~3 个白色带蓝边的「Z / z」符号飘在头部左上方。
构图：横向躺卧，身体贴近画布下沿。
```

### 6. error（出错）— 1:1 方，建议 1024×1024 ｜ 原素材 100×106 ｜ 总览格：第二行左
```text
姿势：蹲坐在地上，双手抱膝或撑地，尾巴无力地垂在身侧，肩膀垮下来。
表情：眉毛下垂、眼睛含泪、嘴角向下撇。
可选道具：旁边一块裂开的空白卡片/告示牌，上面画一个「✕」（不要写文字）。
```

### 7. icon（插件管理器图标）— 1:1，256×256
```text
画一张头像/半身特写：头部 + 女仆发带 + 两侧鲸鱼鳍耳 + 亮蓝蝴蝶结，正面看向观众，微笑。
透明背景，白色描边，主体占满画面（上下左右各留 5% 以内）。
```

## 五、生成与交付要求

- **同一个模型、同一轮会话**生成全部图片，每张都传同一组参考图 + 主提示词；尽量固定 seed，避免服装和发色漂移。
- **必须透明背景**。若生成工具不支持，就出**纯白 #FFFFFF 平背景**（无渐变、无阴影），我后期抠图——但头发边缘会略有损失，优先让模型直接出透明 PNG。
- 长边 1000~1600 px 即可；比例按上表，不必强求精确像素，我接入时会裁剪到目标比例。
- 文件名建议直接对应状态：`resting.png`、`working.png`、`waiting.png`、`celebrate.png`、`sleeping.png`、`error.png`、`icon.png`。
- 逐张自检：①透明底；②只有一个角色；③无文字/水印/气泡；④耳鳍、呆毛、围裙小鲸鱼刺绣、尾巴四个特征都在；⑤底边贴齐、顶部没留大片空白；⑥与参考图的服装配色一致。
